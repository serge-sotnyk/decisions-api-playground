# Jev: перевірка розуміння українського тексту

Повний український приклад із невеликого експерименту: один текст, дев’ять запитань і по чотири варіанти відповіді. Формулювання збережені з початкового тесту, включно з «Марко ледь не запізнився».

## Як відтворити

У TypeSafe Playground встав JSON із розділу **State** у поле **State**, а JSON із розділу **Questions** — у поле **Questions**. У вихідному експерименті на скриншотах зазначено модель `jev-latest`; точну версію моделі не зафіксовано.

**Ключ відповідей, пояснення та результати нижче не додавай до запиту.** Вони призначені лише для перевірки.

## State

```json
{
  "text": "Марко ледь не запізнився на внутрішню нараду, а Олена прийшла на двадцять хвилин пізніше домовленого. «Олено, та ти просто взірець пунктуальності!» — сказав він, глянувши на годинник. «Учора так і не дійшли руки прочитати лист зі зміною часу», — пояснила вона. Олену попросив переробити висновки Марко: його непокоїли не цифри у звіті, а надто сміливі узагальнення. «Не переписуй увесь звіт: зміни лише останній абзац», — уточнив він. Не всі зауваження Марка Олена вважала слушними, проте сперечатися не стала. Зустріч із клієнтом вирішили відкласти до п'ятниці, а не скасувати. «Навряд чи клієнт зрадіє», — зауважила Олена. Його відповіді вони ще не отримали."
}
```

## Ключ відповідей

Це очікувані значення для перевірки початкового тексту, а не приклад структури відповіді API.

```json
{
  "q1": "c",
  "q2": "a",
  "q3": "d",
  "q4": "b",
  "q5": "b",
  "q6": "a",
  "q7": "c",
  "q8": "b",
  "q9": "d"
}
```

| Питання | Відповідь | Що перевіряється |
| --- | --- | --- |
| `q1` | `c` | «Ледь не запізнився» — запізнення не сталося; запізнилася лише Олена. |
| `q2` | `a` | Іронічний докір, оформлений як похвала пунктуальності. |
| `q3` | `d` | Фразеологізм «не дійшли руки»: Олена так і не взялася читати листа. |
| `q4` | `b` | Ролі учасників визначаються відмінками, а не порядком згадування: Марко попросив Олену. |
| `q5` | `b` | Перефразування «сміливі узагальнення» / «далекосяжні висновки» та протиставлення «не цифри, а…». |
| `q6` | `a` | Обмеження «лише» та синонімія «останній» / «фінальний». |
| `q7` | `c` | «Не всі» не означає «жодне»: принаймні одне зауваження не вважалося слушним. |
| `q8` | `b` | «Відкласти» / «перенести» на відміну від «скасувати». |
| `q9` | `d` | Припущення Олени не є встановленим фактом про реакцію клієнта. |

## Контрольні зміни першого речення

Замінюй тільки наведений початок `text`. Продовження «, а Олена прийшла…», решту тексту та всі запитання залишай незмінними. Ключ для `q2`–`q9` не змінюється.

| Початок тексту | Очікувана відповідь на `q1` |
| --- | --- |
| Марко ледь не запізнився на внутрішню нараду | `c` — лише Олена |
| Марко таки запізнився на внутрішню нараду | `a` — обоє |
| Марко ледве встиг на внутрішню нараду вчасно | `c` — лише Олена |
| Марко трохи запізнився на внутрішню нараду | `a` — обоє |

Це очікувані відповіді, а не твердження, що всі чотири варіанти були запущені. Зафіксовані результати наведено окремо.

## Зафіксовані результати

Результати переписані зі скриншотів експерименту; це не результати нового запуску цих файлів.

Для початкового тексту модель обрала `a, a, d, b, b, a, c, b, d`: **8 правильних відповідей із 9**, помилка лише в `q1`.

| Варіант першого речення | Очікувано | Вибір Jev | Відсоток біля обраного варіанта | Поле `Confidence` |
| --- | --- | --- | --- | --- |
| «Ледь не запізнився» | `c` | `a` — помилка | 60% | 48% |
| «Таки запізнився» | `a` | `a` — правильно | 94% | 92% |

У початковому запуску біля правильної відповіді `c` на `q1` показано 36%. Для `q2`–`q9` обрані правильні відповіді; інтерфейс показав 100% біля кожної з них і `Confidence: 100%`.

Для варіанта «таки запізнився» на частковому скриншоті також видно правильну відповідь `q2 = a`. Результати `q3`–`q9` цього зміненого запуску на ньому не показані.

Відсотки наведені так, як їх показував інтерфейс. Вони не є виміряною на незалежній вибірці частотою правильних відповідей; показані 100% не означають гарантії правильності.

## Межі висновків

Це діагностичний приклад, а не репрезентативний бенчмарк. Дев’ять запитань стосуються одного тексту; частина запитань повторює потрібні для відповіді фрагменти. Один такий результат не встановлює загальної якості роботи українською.

У відповідній англійській адаптації початкового тесту також отримано 8/9 з помилкою в `q1` на конструкції `almost late`. Це свідчення того, що виявлений збій не обмежується українським формулюванням, але не доказ однакової якості двома мовами загалом. Англійський приклад адаптовано, а не перекладено граматично один до одного: зокрема, у `q4` відмінки замінено пасивною конструкцією.
