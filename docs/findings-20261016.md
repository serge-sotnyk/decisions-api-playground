# Findings — October 16, 2026

The follow-up completed **480 measured requests and 18 warmups**, with five
repetitions per condition. All 498 requests succeeded, all returned the requested
model ID, and none had missing usage or a refusal. There were 1,200 measured
question attempts, covering the same fixed examples as the first run.

See the [full report](../results/published/20261016-main/report.md),
[records](../results/published/20261016-main/records.jsonl), and
[methodology](methodology.md). The [October 9 results](findings.md) remain unchanged.

## Overall result on this fixed workload

| Model | Correct / measured question attempts | Accuracy | Cost of 166 requests, USD |
|---|---:|---:|---:|
| Jev 1.13 | 370/400 | 92.50% | 0.008552040 |
| Jev 1.14 | 385/400 | 96.25% | 0.008551578 |
| Decisions | 380/400 | 95.00% | 0.011179300 |

Jev 1.14 scored 1.25 percentage points higher than Decisions and cost about **24%
less** for the same request mix. Accuracy excludes warmups; cost includes them.
The accuracy aggregate weights every question attempt equally, so nine-question
requests contribute more than single-question requests. Repeated answers are not
independent examples. This is a descriptive result for this workload, not evidence
of general superiority. Cost also depends on the task: Decisions was cheaper on
the short image traps, as detailed below.

Jev 1.14 corrected the English “almost late” text error in all five repetitions.

Decisions' small Ukrainian PNG error was q6: it chose to leave the report entirely
unchanged instead of editing only the final paragraph. This occurred in all five
repetitions; q1 was correct in that condition.

## Wording, traps, and stability

In the wording block, Jev 1.14 answered the English “almost late” variant correctly
5/5 times and the Ukrainian counterpart **3/5** times. The latter differs from
the 2/5 result when all nine questions were asked. These are separate conditions,
not enough evidence that one question format is better.

Jev 1.13 failed that variant in both languages; Decisions failed it in Ukrainian
only. All three models answered the other three wording variants correctly in
every repetition. Only Jev 1.14's Ukrainian q1 choices changed across repetitions,
in both the original and wording blocks. Every other question/condition kept the
same selected answer, including stable errors.

Both Jev versions passed all three added traps in both languages and all input
modes. Decisions also passed them except for the small Ukrainian negation PNG:
it interpreted “не забула надіслати” incorrectly in all five repetitions. The
white margins therefore did not eliminate this previously observed failure.

## Confidence is still not an error detector

Jev 1.14's incorrect Ukrainian text answers had confidence 0.33–0.35 with nine
questions and 0.35–0.43 with q1 alone. However, one correct q1-only answer had
confidence 0.32. Confidence cannot cleanly separate the two outcomes here.

Jev 1.13 was sometimes confidently wrong on images: English full-size q1 had
median probability **89%** on the wrong choice and median confidence **0.85**.
When text and images are pooled, correct/incorrect confidence ranges overlap for all three models. The
separation observed for Jev's text-only October 9 sample does not extend to this
combined set of conditions. The image-only subset tells a different story.

Decisions' Ukrainian text error received 89% on the wrong answer, 9% on the
correct one, and confidence 0.85. Conversely, its small Ukrainian PNG q6 error
had confidence only **0.07**, with 30% on the selected wrong option versus 29%
on the correct one. The small negation PNG error had confidence 0.68. Scores
provide useful diagnostics but are not validated probabilities of correctness.

### Image-only confidence

The following ranges include only measured PNG and small-PNG answers, with text
requests and warmups excluded. Each model returned 230 correct and 10 incorrect
image answers. The ten errors per model are just two question/condition
combinations, each repeated five times.

| Model | Incorrect-answer confidence | Correct-answer confidence |
|---|---:|---:|
| Jev 1.13 | 0.33–0.88 | 0.29–1.00 |
| Jev 1.14 | 0.39–0.60 | 0.73–1.00 |
| Decisions | 0.07–0.68 | 0.36–1.00 |

**Only Jev 1.14 separated the two confidence ranges on images in this run:**
every incorrect image answer had lower confidence than every correct image
answer. Its text errors and uncertain correct text answers explain the overlap
in the combined analysis. Jev 1.13 and Decisions had overlapping image ranges.

On the same full-size English PNG q1, both Jev versions were wrong in all five
repetitions, but median confidence fell from **0.85 in 1.13 to 0.49 in 1.14**;
median probability assigned to the wrong choice fell from **89% to 62%**.
The error persisted while the new version signaled more uncertainty.

This observed separation is useful diagnostic evidence, not a validated
confidence threshold or proof of calibration. A threshold selected after seeing
these few fixed examples needs evaluation on new data. Confidence and
selected-choice probability remain distinct fields, and their calibration is
not assumed equivalent across models.

## Latency and cost

Median HTTP latencies below cover a complete original Ukrainian request with
nine questions, including network and upload. Each median uses five measured
requests; warmups are excluded. Min–max values and other blocks are in the report.

| Model | Text, ms | PNG, ms | Small PNG, ms |
|---|---:|---:|---:|
| Jev 1.13 | 265.03 | 353.94 | 316.74 |
| Jev 1.14 | 270.14 | 373.49 | 359.49 |
| Decisions | 276.72 | 317.83 | 426.83 |

For the original passage, image modes had higher median latency than text for
every model and language. A smaller PNG was not always faster. Short-trap
latencies were closer; these are one-session measurements, not service guarantees.

The whole run cost **\$0.028282918**, calculated from reported input tokens and
the frozen tariffs, including warmups. Each model handled the same 166 requests:
Jev 1.13 cost \$0.008552040, Jev 1.14 cost \$0.008551578, and Decisions cost
\$0.011179300. This is a usage-based estimate, not an invoice reconciliation.

For 1,000 original Ukrainian requests, Jev 1.14 cost approximately **\$0.122556
for text, \$0.164396 for PNG, and \$0.121464 for small PNG**; Decisions cost
\$0.189600, \$0.223200, and \$0.183300 respectively. Images were not uniformly
more expensive: token accounting and question length matter. On the short traps,
both Decisions image modes were cheaper than the corresponding Jev modes in
both languages, despite Decisions' higher per-token tariff.

## Historical comparison and limits

The October 9 artifacts and methodology are archived separately. Fourteen PNGs
gained margins for this run, so their cross-date differences cannot be attributed
solely to a model update. The two full-size original PNGs are byte-identical to
the old files. Even on the unchanged Ukrainian full-size PNG, Decisions changed
from 8/9 in the old run to 9/9 in this run under the same returned model name.
That name alone does not establish unchanged backend behavior across dates; the
cause of this difference was not isolated.

Five repeats measure observed stability and latency on a few examples. They do
not add independent tasks or establish a general winner. Clean synthetic text
images also do not establish performance on scans, photographs, or handwriting.
